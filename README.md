## Outer Wilds Items - Github

In this repo, you will find:

- A .unitypackage file with the setup of the mod in unity, with most of the files in it
- Some .blend files for the models in the mod
- Some .pdn files (Paint.NET files) for the textures in the mod
- Some SFX files for the sounds in the mod
- The image that shows up in the thunderstore page
